📸 pothooo booth maoel

pothooo booth maoel adalah aplikasi photobooth berbasis web yang dirancang untuk mengabadikan momen manis secara langsung dari peramban (browser) Anda. Dengan antarmuka yang estetis, aplikasi ini menyediakan berbagai pilihan templat frame menarik, filter foto bawaan, pengambilan foto langsung lewat kamera Web, serta pengunduhan hasil foto berkualitas tinggi.

✨ Fitur Utama

🎨 10 Pilihan Frame Estetis & Unik
Tersedia beragam desain frame menarik seperti Lilac Dream Strip, Mint Polaroid Grid, Vintage Newsprint, Strikeapose Grid, dan lain-lain.

🎭 6 Filter Foto Real-time
Terapkan filter secara instant ke seluruh slot foto: Normal, Hitam Putih, Vintage, Cerah, Dingin, dan Lembut.

📷 Dukungan Kamera Web (Webcam)
Mengambil foto langsung dari kamera laptop atau ponsel dengan alur kerja pengisian slot foto otomatis (sequential photo filling).

📤 Pengunggahan Foto dari Galeri
Impor foto pilihan Anda dari perangkat secara tunggal maupun jamak (multi-upload).

🖼️ Mode Interaktif & Sunting Slot
Klik langsung pada area slot foto di preview untuk mengganti atau memperbarui foto pada slot tertentu saja.

📥 Ekspor Gambar Berkualitas Tinggi (Canvas Render)
Unduh hasil gabungan foto dan frame favorit Anda dalam format PNG beresolusi tinggi yang siap dibagikan ke media sosial (seperti Instagram Story).

📱 Desain Responsif (Mobile-friendly)
Tampilan yang disesuaikan untuk perangkat ponsel maupun komputer desktop.

🚀 Demo & Penggunaan Langsung

Aplikasi ini dapat dijalankan langsung di peramban tanpa memerlukan server backend atau proses build.

Anda dapat mencobanya dengan mengkloning repositori ini dan membuka berkas index.html langsung di browser, atau menggunakan GitHub Pages.

🛠️ Teknologi yang Digunakan

HTML5 — Struktur aplikasi web dan elemen modal.

CSS3 — Tata letak responsif (Flexbox & Grid), animasi, serta variabel CSS untuk tema visual.

JavaScript (Vanilla JS) — Logika interaktif, manipulasi DOM, manajemen state foto.

HTML5 Canvas API — Untuk penggabungan gambar (rendering layer), penerapan filter CSS ke canvas, dan ekspor berkas gambar.

MediaDevices API (getUserMedia) — Akses dan streaming kamera web real-time.

SVG Inlining & Blob URL — Pembuatan templat frame vektor dinamis secara langsung di sisi klien.
